# TokenFlow working agreement

- User approved autonomous, reversible implementation within this project. Do not repeatedly ask for routine confirmations. Explain concrete blockers and better alternatives.
- Build the context-optimization product described in docs/product.md; prioritize benchmark evidence before infrastructure.
- Preserve instructions, latest query, conversation order, code and pinned facts. Fail explicitly on impossible budgets.
- Never present synthetic fact retention or mocked provider outputs as real answer quality, real token billing or cost savings.
- Keep API keys out of code, logs and reports. No raw prompts in operational metrics.
- No Kubernetes, model training, multi-cloud or routing until product evidence justifies it.
- Run pytest and ruff before delivery. Prefer independent regression cases over tests that merely repeat implementation logic.

- Use English in all project documentation, comments, filenames, commit messages, and GitHub issues. Keep necessary multilingual regression payloads in Unicode-escaped source/fixture literals.
